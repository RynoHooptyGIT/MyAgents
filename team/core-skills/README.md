# Core Skills

Cross-phase skills ported from bmad `src/core-skills/`. Unlike workflows in
`team/workflows/<phase>/`, these skills are invoked from any phase.

- `bmad-review/` — canonical code + prose review lenses
- `bmad-deep-recon/` — research-trio consolidation
- `bmad-party-mode/` — multi-agent collaboration (ported in Plan E)
- `bmad-forge-idea/`, `bmad-advanced-elicitation/` — added by Plans D and F
- `v6-shims/` — legacy skill-id redirect stubs
