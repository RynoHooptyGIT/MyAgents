# Shared install manifest — the single list of tooling files that scripts/setup.sh
# (fresh install) and scripts/team-update.sh (update from upstream) both install.
# Applied by apply_manifest in scripts/lib/install-manifest.sh.
#
# Format: mode<TAB>src<TAB>dst[<TAB>group]   (# comments and blank lines are ignored)
#   copy  copy, overwriting dst
#   init  copy only if dst is absent (project-owned after the first install)
#   exec  copy, overwriting dst, then chmod +x
# src is relative to the source root; a glob is allowed in the basename only.
# dst is relative to the destination root; a trailing / means "into this directory",
# otherwise it is the destination file path (single-file src only).
# group is `core` (tool-agnostic; the default when the column is absent) or
# `claude` (Claude Code hooks and settings). apply_manifest --group NAME installs
# only that group; with no --group every entry is applied.
# Repo-only dev tools (scripts/test.sh, scripts/check-settings-drift.sh) are
# deliberately not listed: they depend on files a target project does not have.
