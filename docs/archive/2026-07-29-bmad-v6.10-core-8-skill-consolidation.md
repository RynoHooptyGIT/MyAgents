# bmad v6.10.0 — Plan B: Core 8-Skill Consolidation

> **STATUS: LANDED** (2026-08-23) — artifact-verified. Shipped `team/core-skills/{bmad-review,bmad-deep-recon,v6-shims}`. See `docs/sync-notes-v6.10.0.md`.

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port bmad's streamlined 8-skill core: consolidate the review + editorial skills into a single `bmad-review` skill with named lenses, add `bmad-deep-recon` (the research-trio consolidation), and stage v6 shims that keep old skill IDs discoverable while pointing at the new home.

**Architecture:** Additive port under `team/core-skills/` (a new fork directory that mirrors bmad's `src/core-skills/`). This keeps the phase-based `team/workflows/<phase>/` tree for workflows and gives cross-phase skills like `bmad-review`, `bmad-deep-recon`, and `bmad-party-mode` their own home. Plan A's Task 5 explicitly protected quick-dev/dev-auto from moves — they stay put under `team/workflows/implementation/`. The consolidated review lenses in `bmad-review` are the canonical prompts referenced by Plan C.

**Tech Stack:** Markdown, TOML. Python `scripts/` under `bmad-review` and `bmad-deep-recon` are NOT ported (fork lacks the `_bmad/config.toml` / uv-driven renderer these scripts assume). Skill.md files that reference these scripts have the script invocation swapped for direct-read instructions, matching the Plan A precedent.

**Upstream refs ported:**
- `c23f2340` streamline core to 8-skill set with merged review + editorial (#2603)
- `8b4da791` group v6 shims and merge editorial review into bmad-review as lenses (#2608)
- `bb45db4a` consolidate research trio into bmad-deep-recon (#2611)

**Out of scope:** Python scripts (`word_metrics.py`, `recon_kit.py`, their tests), i18n docs, installer wiring.
