## Task 2: Reference audit before deletion

Before deleting a workflow, find every file that references it. Broken references become dead links; either fix or acknowledge them.

- [ ] **Step 1: Enumerate references**

```bash
echo "=== references to create-story ==="
grep -rln --include='*.md' --include='*.yaml' --include='*.yml' --include='*.xml' \
  --include='*.csv' --include='*.toml' \
  'create-story' team/ docs/ | grep -v 'team/workflows/implementation/create-story/'

echo "=== references to dev-story ==="
grep -rln --include='*.md' --include='*.yaml' --include='*.yml' --include='*.xml' \
  --include='*.csv' --include='*.toml' \
  'dev-story' team/ docs/ | grep -v 'team/workflows/implementation/dev-story/'

echo "=== references to automator ==="
grep -rln --include='*.md' --include='*.yaml' --include='*.yml' --include='*.xml' \
  --include='*.csv' --include='*.toml' \
  'automator' team/ docs/
```

Note each file. Categorize:
- **Rewrite:** the reference points to something that has a canonical replacement (e.g., `create-story` in an agent-manifest should become `quick-dev`).
- **Delete:** the reference is orphaned (a link inside a plan or historic doc that no longer applies).
- **Leave:** the reference is in a historic plan file under `docs/plans/` — preserve as history, do not touch.

- [ ] **Step 2: Draft the fix list**

For each file that needs a rewrite, note the exact sed replacement. Suggested defaults:
- `create-story` → `bmad-spec` (spec-kernel-distiller subsumes story creation) or `quick-dev` (if the reference was about the implementation loop)
- `dev-story` → `quick-dev`
- `automator` → `dev-auto` (its direct replacement)

Only apply after confirming per-file — do not blindly sed the whole tree.

- [ ] **Step 3: Apply rewrites file-by-file**

For each file identified as "Rewrite":
```bash
# Example, one file at a time:
sed -i '' 's|dev-story|quick-dev|g' team/agent-manifest.csv
```

Verify each change with `git diff` before proceeding to the next.

- [ ] **Step 4: Commit reference rewrites**

```bash
git status | head -30
git add -p   # stage only the rewritten reference files
git commit -m "refactor: retarget legacy skill references before deprecation

Retargets create-story → bmad-spec/quick-dev, dev-story → quick-dev,
automator → dev-auto references across manifest, agents, and workflows.
Historic plans under docs/plans/ retain original terminology.

Ported from bmad commits: e7af627e, 4b6288d8"
```
