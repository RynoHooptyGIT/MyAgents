# bmad v6.10.0 — Plan D: New Skills (forge-idea, spec, prd, ux)

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port four skills new or substantially rewritten in v6.7–v6.10 into the fork: `bmad-forge-idea` (Phase-0 idea forging), `bmad-spec` (Phase-2 spec kernel distiller producing the stories.yaml contract), `bmad-prd` (Phase-2 PRD facilitator overhaul), and `bmad-ux` (Phase-2 UX skill on the DESIGN.md + EXPERIENCE.md spine).

**Architecture:** All four are static-content ports. `bmad-forge-idea` lands under `team/core-skills/` (cross-phase idea forging). The three Phase-2 skills (`bmad-spec`, `bmad-prd`, `bmad-ux`) land under `team/workflows/planning/` alongside the existing `prd/` and `create-ux-design/` workflows. Python helper scripts (`resolve_personas.py`, `lint_spine.py`) are NOT ported — their invocation lines in the skill files get a note explaining the omission, matching the Plan A precedent.

**Tech Stack:** Markdown, TOML. No Python, no HTML template (`validation-report-template.html` files are copied but not rendered — flag as static asset).

**Upstream refs ported:**
- `005ef110` add bmad-forge-idea skill + docs (#2492)
- `aa6dece0` bmad-spec kernel distiller skill (#2417)
- `c52c9b5b` new PRD skill + product-brief updates (#2378)
- `71136bc6` overhaul PRD facilitation, discipline, and validation (#2385)
- `ee47e30c` bmad-ux spine-based DESIGN.md + EXPERIENCE.md (#2413)

**Out of scope:** `bmad-prfaq` (fork already has product-brief; prfaq belongs in a follow-up), Python scripts, i18n docs, `bmad-manifest.json` entries (the fork's manifest.yaml handles registration).

**Depends on:** Plan B (`team/core-skills/` root exists and has `README.md`).
