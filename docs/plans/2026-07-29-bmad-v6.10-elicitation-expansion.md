## Task 2: Merge fork's 50 methods into upstream's 71

Fork's `methods.csv` uses a different `num` ordering and may contain methods not present upstream (or vice versa). Merge by `method_name` (col 3): the union of both files, deduped, with `num` renumbered sequentially.

- [ ] **Step 1: Save the two source files to temp**

```bash
mkdir -p /tmp/elicit-merge
git cat-file -p bmad/main:src/core-skills/bmad-advanced-elicitation/assets/methods.csv \
  > /tmp/elicit-merge/upstream.csv
cp team/workflows/advanced-elicitation/methods.csv /tmp/elicit-merge/fork.csv
```

- [ ] **Step 2: Extract method names from both**

```bash
tail -n +2 /tmp/elicit-merge/upstream.csv | awk -F',' '{print $3}' | sort -u > /tmp/elicit-merge/upstream-names.txt
tail -n +2 /tmp/elicit-merge/fork.csv | awk -F',' '{print $3}' | sort -u > /tmp/elicit-merge/fork-names.txt

echo "--- in upstream, not in fork ---"
comm -23 /tmp/elicit-merge/upstream-names.txt /tmp/elicit-merge/fork-names.txt | head -30
echo "--- in fork, not in upstream ---"
comm -13 /tmp/elicit-merge/upstream-names.txt /tmp/elicit-merge/fork-names.txt | head -30
```

Note the two lists. The first is what Plan F must add; the second is what the fork's legacy set has that upstream lacks — those are preserved in the merge.

- [ ] **Step 3: Build the merged CSV**

```bash
python3 <<'PY'
import csv

def read(path):
    with open(path) as f:
        r = csv.DictReader(f)
        return list(r), r.fieldnames

up_rows, up_fields = read('/tmp/elicit-merge/upstream.csv')
fk_rows, fk_fields = read('/tmp/elicit-merge/fork.csv')

# Prefer upstream schema — it is the authoritative one going forward.
assert up_fields == fk_fields, f"schema mismatch: upstream={up_fields} fork={fk_fields}"

seen = {}
for row in up_rows:
    seen[row['method_name']] = row
# Fork-only methods keep their fork rows (upstream wins on name conflicts).
for row in fk_rows:
    seen.setdefault(row['method_name'], row)

merged = list(seen.values())
# Renumber sequentially starting at 1.
for i, row in enumerate(merged, 1):
    row['num'] = str(i)

with open('team/core-skills/bmad-advanced-elicitation/assets/methods.csv', 'w', newline='') as f:
    w = csv.DictWriter(f, fieldnames=up_fields)
    w.writeheader()
    w.writerows(merged)

print(f"wrote {len(merged)} methods (upstream={len(up_rows)}, fork={len(fk_rows)}, union={len(merged)})")
PY
```

Expected output: `wrote N methods (upstream=71, fork=50, union=…)`. The union count depends on overlap.
